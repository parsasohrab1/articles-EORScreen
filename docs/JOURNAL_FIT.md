## Fit

The petroleum issue lists enhanced oil recovery and data-driven petroleum work. This run screens historical EOR families on a public project table and compares the sets with the 1997 numeric limits. It is not a reservoir simulation, not a CO2-storage design, and not a new recovery fluid.

The power-systems issue lists markets, storage, hydrogen, microgrids, wind, and HVDC. This run is none of those.
